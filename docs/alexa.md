# Adding notes by Alexa

You can add notes by saying them to an Echo: "Alexa, ask Nick Notes to add Shopping oat milk". Alexa reads each note back, so you know straight away if it misheard. It uses the same commands as [texting notes in](text-messages.md).

It only works on Echos signed in to the admin's Amazon account.

## Setting it up (once)

1. Go to **Settings**, then **Alexa**, and tap **Link Alexa**.
2. A six-digit code appears. Say "Alexa, ask Nick Notes to link", then the code. It works for 15 minutes.
3. Alexa says "Linked", and Settings shows **Linked to Alexa**.

Everyone who talks to that Echo adds notes to the notebook it's linked to.

## The commands

Start with "Alexa, ask Nick Notes to", then one of these:

| Say | What it does |
|---|---|
| **add** *tab* *note* | Adds a note in that tab |
| **new** *note*, or **note** *note* | Adds a note with no tags |
| **due** *when* | Sets a due date on the note you just added |
| **reset new** | Makes all your New notes Active |
| **email tab** *tab* | Emails you the notes in that tab |

For example:

> "Alexa, ask Nick Notes to **add Shopping** oat milk and bin bags"

Alexa says "Saved to Shopping: oat milk and bin bags." The note has the Shopping tab's tags, so it shows in that tab. If no tab has the name you said, everything after "add" is the note, with no tags, and it shows in **All**.

> "Alexa, ask Nick Notes, **due** tomorrow at 3pm"

This sets the due date of the note you added last, as long as that was in the last 5 minutes.

Every command needs its first word. "Alexa, ask Nick Notes oat milk" isn't understood: say "add" or "new" first.

## Several notes in a row

Say "Alexa, open Nick Notes". Alexa asks what you'd like to add, and keeps listening after each note ("Anything else?"), so you don't need to say "Alexa, ask Nick Notes" each time. Say "stop" or "that's all" when you've finished.

## Tabs that are hard to say

If Alexa often mishears a tab's name, give the tab a **spoken name** in its settings, e.g. "do it yourself" for "DIY": edit the tab in **Settings** and fill in **Spoken name**. See [Spoken names](text-messages.md#spoken-names).

## When something goes wrong

If a note can't be saved, Alexa says why, and a notification is sent to your devices with what Alexa heard, so you can add it by hand. The Alexa app on your phone also shows what Alexa heard.

If Alexa says it isn't linked, link it again in **Settings**, under **Alexa**.

## Unlinking

In **Settings**, under **Alexa**, tap **Unlink**. Alexa then stops adding notes.
