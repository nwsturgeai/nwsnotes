# Changing the Tags of several notes at once

Instead of editing notes one by one, you can change the Tags of many at once.

1. With the area at the bottom expanded, tap the **checklist** button.
2. Tap the notes you want to change. **All** and **None**, in the filter row, select every note in the list or none. Holding the checklist button for a second starts with every note selected.
3. Tap Tag pills in the area at the bottom: a Tag the selected notes don't all have is added to them all; tap again to take it off them all.
4. Tap the **tick** to save the changes, or the checklist button again to stop without changing anything.

Once you've tapped a Tag, the selection is fixed, so the notes you're changing don't shift around.

This isn't available while you're offline.
