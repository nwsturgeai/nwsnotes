# Putting notes in order

New notes go at the bottom of the list. You can put your notes in any order you like.

## Edit order

Tap the **edit order** button at the far right of the filter row (the one with lines of different lengths). Each note then gets:

- a **grip** at its left: hold it and drag the note up or down, then let go;
- **double up** and **double down** arrows, which move the note straight to the top or the bottom.

Tap the button again (now a clipboard with a tick) when you've finished.

## Moving a note to another tab

While you're putting notes in order, you can also drag a note onto another tab's name (along the top or down the left) and let go. A box lists how the note's tags will change, for example "Area: Work → Home". Choose **OK** to move it, or **Cancel**. If you do nothing, it's moved after 3 seconds.

The note gets the tags that put it in the new tab, and loses the ones that put it in the tab it came from. If you tick "Auto-accept note-to-tab drags in this window for the next 5 minutes?", your next drags in this window are moved straight away, with a short message saying what changed.

You can't drop a note on "All" or on the tab you're on, and you can't move notes shared with you.

## One order everywhere

Your notes have one order, shared by every tab. So if note A is above note B on one tab, it's above it on every tab that shows them both. Moving a note on one tab moves it only among the notes that tab shows; notes the tab doesn't show keep their places.

## Adding a note at the top

See [Writing and editing notes](writing-notes.md): press Ctrl+Enter, or hold the + button for a second.

Ordering needs a connection to the server, so it isn't available while you're offline.
