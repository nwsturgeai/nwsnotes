# Tabs

A tab is a saved filter: a quick way to see just one group of notes, such as "Work" or "Shopping". Tabs are along the top of the screen; tap one to switch to it. The first tab, **All**, always shows every note (apart from those in the Bin).

Each tab you switch to is like opening a new page: the browser's **Back** button (or your phone's back button) goes to the tab you were on before, and reloading the page keeps you on the same tab. While you're editing a note or selecting notes, Back does nothing until you've finished.

## Making a tab

In **Settings**, under **Tabs**, tap **Add tab**:

1. Give it a short name.
2. Choose which Tags it shows. Within one Category, ticking several Tags shows notes with any of them. If you choose Tags from several Categories, a note must match each of them.
3. **Save**.

Tap a tab in Settings to change it or delete it. Deleting a tab doesn't delete any notes.

## Adding notes on a tab

New notes added while a tab is open get its Tags automatically, so they appear in that tab. If the tab allows several Tags from one Category, you'll be asked to pick one.

## Tabs down the left

If you have lots of tabs, some can go in a narrow strip down the left of the screen instead. Open the tab in Settings and switch it to **Left**. "All" can go on the left too.

## Too many tabs to fit

When the tabs don't all fit across the top, the last few go into a **…** menu at the end.

## Note counts

Switch on **Tab counts** in Settings to see how many notes each tab has, for example "All (153)". The counts are for the tab itself; ticking filters or searching doesn't change them.

## Order of tabs

In Settings, drag tabs by their grips, or use the arrows. "All" always stays first.
